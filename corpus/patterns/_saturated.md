# Saturated Cross-Corpus Patterns

Catalog of cross-architecture patterns that have reached saturation
threshold (typically 5+ instances across diverse domains) during
Layer A build. These are inputs to Layer D synthesis when Layer A
completes.

## Pattern: Architectural-discipline-LOSS-as-anti-asset

### Status
Saturated at 5 instances, batch 5, May 2026.

### Mechanism
Discipline-as-asset inverted into anti-asset that actively resists
recovery.

### Instances
- boeing-aerospace: cost-vs-engineering cultural shift post-MD merger
  1997. Reconstitution: Ortberg CEO 2024.
- ford-motor: capital-allocation discipline loss + EV transition
  mismanagement. Reconstitution: Farley CEO + Ford Pro focus.
- general-electric: financial-engineering substituting for operating
  discipline (Welch → Immelt). Reconstitution: Culp turnaround
  2018-2024 + 2024 3-way split.
- intel: tick-tock-cadence execution failure (10nm 2015-2019).
  Reconstitution: Lip-Bu Tan 2025 restructuring.
- refinitiv-eikon: ownership-transition sequence interrupting
  continuous architectural discipline. Reconstitution: LSEG 2021
  integration + Microsoft AI partnership 2022.

### Invariant features
- Discipline-as-asset inverted into anti-asset
- Active reconstitution attempts in progress, outcomes uncertain
- Named comparator-survivors retained discipline (Airbus, Toyota,
  Honeywell/Roper, TSMC+AMD, Bloomberg)
- Discipline-loss takes ~3-5 years; reconstitution takes longer or
  fails (structural asymmetry)
- Substrate didn't disappear (Boeing still flies, Intel still fabs);
  architecture's discipline degraded

### Layer D synthesis notes
- Anti-pattern candidate: architectures dependent on continuous
  operator-attention discipline vs architectures with institutional-
  discipline-substitution mechanisms
- Parent-goal implication: solo-billion architectures must have
  discipline-maintenance mechanisms proportional to scale; recovery
  cost from discipline loss exceeds original accumulation

### Comparator survivor pattern
Surviving comparators in each case retained discipline through:
- Continuous founder-CEO (Bloomberg/Bloomberg-the-person,
  Huang/NVIDIA, Chang→Wei discipline-line at TSMC)
- Strong successor calibration (Toyota Toyoda family, Honeywell/Roper
  acquisition discipline)
- Cultural-institutional reinforcement (Airbus engineering culture
  continuity)

### Layer-architecture placement note
This pattern belongs in Layer D (anti-patterns / evaluative
constraints), not Layer A (substrate primitives). The distinction:

- Layer A reference architectures: substrate the proposer composes
  from (what configurations have produced value capture)
- Layer D anti-patterns: constraints the proposer evaluates against
  (what configurations have demonstrably failed or are demonstrating
  failure-in-progress)

The discipline-loss pattern is specifically about TIME — the proposer
should consider whether a candidate architecture's proposed scale
and discipline-maintenance mechanisms are coherent given the
asymmetric loss/reconstitution cost.

Sprint 12 V7 proposer prompt design should reference this layer-
architecture distinction. Layer D consolidation happens after Layer
A completes; this is not a Sprint 12 blocker.
