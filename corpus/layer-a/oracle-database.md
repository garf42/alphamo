
# Oracle Database

## Research Summary

Verified primary facts as of May 2026: Oracle Corporation founded 1977 by Larry Ellison, Bob Miner, Ed Oates as Software Development Laboratories (Oracle Version 2 commercial RDBMS launched 1979 — no Version 1, marketing tactic implying maturity). Ellison Chairman+CTO since 2014 (passing CEO to Mark Hurd + Safra Catz; Hurd died 2019; Catz remains CEO). Q2 FY2026 cloud revenue $8B (+33%, ~50% of total); OCI revenue $4.9B (+84%); OCI consumption +62% Q4 FY2025; MultiCloud revenue triple-digit growth FY2026 guide; Cloud@Customer datacenters grew 104% YoY; 29 datacenters live + 30 building in FY26. RPO (Remaining Performance Obligations) $553B early 2026 — long-term AI infrastructure contracts not yet revenue. FY2026 capex ~$50B for AI data center buildout.

Critical force-topology updates training data would miss: (1) **Oracle-OpenAI $300B 5-year cloud deal announced 2025** — one of largest contracts in tech history; 4.5 GW of Stargate data center capacity (electricity ~4M US homes); Abilene Texas 1.2 GW flagship Stargate live; Stargate expansion to 7 GW + $400B+ planned investment. (2) OCI customers including OpenAI, Meta, NVIDIA — Oracle positioning as AI-native hyperscaler late-mover-but-strategic. (3) Database business architecture preserved through cloud + AI extension; legacy on-premises database revenue stable while cloud + OCI accelerates. (4) DB-Engines rankings 2025: Oracle still #1 database (just barely); PostgreSQL + Snowflake + MongoDB all climbing; Snowflake biggest climber to #6 in Q1 2025; cloud-native + open-source pressuring traditional RDBMS. (5) MultiCloud strategy — Oracle Database now available on AWS, Azure, GCP via Oracle Database@AWS + @Azure + @GoogleCloud — architectural extension of database into competitor hyperscaler clouds.
