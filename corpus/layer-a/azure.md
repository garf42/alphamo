
# Microsoft Azure

## Research Summary

Verified primary facts as of May 2026: Azure announced 2008, officially released February 2010 originally as "Windows Azure" (renamed Microsoft Azure 2014). Satya Nadella led Microsoft Cloud and Enterprise group pre-CEO; became CEO February 2014 with cloud-first strategic pivot. FY2025 (June 2025) Azure revenue exceeded $75B with 40% growth; Q2 FY2026 Intelligent Cloud segment $32.9B (+29%); Azure specifically +39% YoY, with ~12 percentage points attributed to AI services. Microsoft Cloud crossed $50B quarterly revenue for first time (+26%). 70+ regions, 400+ datacenters, 60,000+ AI customers. Calendar 2026 capex guided ~$190B. 95% of Fortune 500 use Azure.

Critical force-topology updates training data would miss: (1) **OpenAI partnership restructuring 2025** — exclusive cloud arrangement (2019-2023) ended; ~$250B purchase commitment + multi-vendor relationship; OpenAI products still ship first on Azure but freedom to work with other clouds (now AWS $38B 7-year partnership + AMD 6 GW MI450 deal H2 2026). Sub-pattern A/C boundary case but architecture preserved on Microsoft side — categorize as G7 modification not status change. (2) Azure GenAI primary hosting share 42% (vs AWS 40%) — Azure leads on AI workloads via OpenAI partnership despite AWS 31% overall market share lead vs Azure 24% vs GCP 12%. (3) Azure demand exceeds supply through H1 calendar 2026; Microsoft expects modest acceleration H2 2026 as capacity comes online; ~130K GPUs across Arizona cluster (H100 2023 + H200 2024 + GB200 2025). (4) EU Data Boundary completion February 26, 2025 — contractually commits customer data stays in EU for storage/processing for M365 + Dynamics 365 + Power Platform + most Azure services; sovereign cloud market growing $154B → $823B 2032. Microsoft 365 Copilot in-country processing 15 nations by end-2026. (5) AWS European Sovereign Cloud launched January 2026 — competitive response with EU-citizens-only staff + no parent control; sovereignty competitive dynamics intensifying. (6) June 2025 Microsoft legal director admission to French Parliament that no technical/contractual arrangement overrides CLOUD Act — sovereign cloud architectural limitation acknowledged.
